# ПальмиКвест v25 — временный российский reverse proxy

Это отдельный транспортный слой. Здесь нет кода игры, базы, снимков детей, PIN или секретов. Единственный upstream зафиксирован: https://palmi-quest-istra.slusarevzahar.chatgpt.site. D1/R2 остаются в существующем Sites. Никаких миграций, сбросов и изменения публикации.

## Порядок запуска

1. Timeweb App Platform → отдельное приложение → этот репозиторий → Dockerfile. Выбрать доступный российский регион, минимальную конфигурацию, без дополнительных баз/дисков/бэкапов. Убедиться, что стоимость укладывается в согласованный лимит. Технический HTTPS-домен — без покупки домена и изменения DNS.
2. Первый запуск: `PROBE_ONLY=true`, `PORT=8080`. Не включать игровой прокси до результата проверки. У Timeweb фронтальный HTTPS; порт приложения 8080 указан через EXPOSE.
3. С самого российского контейнера автоматически выполняются GET исходного сайта, публичного API и 91 статического ресурса. `/__proxy/health` означает только живой процесс. **Результат проверки upstream**: `/__proxy/probe`; HTTP 200 и `status: pass` — обязательные файлы доступны с этого узла. Зафиксировать выбранный регион по панели Timeweb: программа не угадывает страну по часовому поясу/IP.
4. Если обязательные проверки не проходят, не выдавать адрес как работающую игру. Проверить DNS/TLS/IPv4 из того же узла; не отключать проверку сертификатов. См. альтернативу ниже.
5. После успеха установить `PUBLIC_ORIGIN` равным фактическому техническому HTTPS-адресу (без пути), `PROBE_ONLY=false`. Выполнить повторное развёртывание. TLS между прокси и upstream проверяется.
6. Через новый домен проверить вход ведущего по существующему имени/PIN, API и cookies. **Вход ChatGPT через OAuth — отдельный внешний сервис и не считается проверенным автоматически.** Основной сценарий мероприятия использует вход ведущего по PIN.
7. Сначала посмотреть текущую production-сессию. Новую тестовую сессию создавать только в согласованном свободном окне, не сбрасывая действующую группу. Подключить два независимых телефона, пройти синхронизацию, сбор деталей, активацию и выдачу уникальных наград. Тестовые призы/игроки не подменяют подтверждение реального сценария.
8. Проверить Android и iPhone через мобильные сети России без VPN; разрешение камеры выдаётся самим пользователем. HTTPS — необходимое, но не достаточное условие работы камеры и акселерометра.
9. Только после подтверждения изготовить три QR: `/#play`, `/#host`, `/#energy` нового фактического домена. PIN/токены в постоянных QR запрещены.

## Особенности

- Все пути, запросы, загрузки, куки, статусы и двоичные файлы передаются в тот же сервер. POST автоматически не повторяется. Игровая механика не меняется.
- Чужой Origin/Host и поддельные заголовки платформенного владельца отвергаются/удаляются. Origin/Referer своего домена согласуются с upstream; защитные свойства cookies и политики браузера не снимаются.
- Изображения/PNG, PDF/ZIP, загрузки и диапазоны байтов не подвергаются текстовой замене. В HTML/JS/CSS/JSON и HTTP-перенаправлениях заменяется только точный исходный домен. API и ответы с cookies не кэшируются прокси.
- **QR на экране пульта** использует текущий адрес и будет новым. **Скачиваемые серверные PDF/PNG/ZIP материалов** формируются upstream и сохраняют прежний адрес; их не использовать вместо трёх отдельно проверенных новых QR.
- Проверка ресурсов охватывает файлы v25. Пользовательские фотографии/озвучка из R2 зависят от конфигурации и требуют отдельной проверки после входа. Личные снимки игроков не загружаются диагностикой.
- WebSocket не используется текущей игрой; upgrade отвергается. При смене механики на WebSocket потребуется отдельная доработка. Лимит одной загрузки 24 МиБ; текстового ответа — 8 МиБ.
- Нет доступа к произвольным URL, D1/R2, файлового сервера, скрытой авторизации или логирования cookies/тел запросов/PIN.

## Если российский узел не достигает upstream

Пользователь разрешил **только российский сервер**: зарубежный relay не создавать. Второй российский ресурс тоже не создан; попытка выбора SPB остановлена по просьбе пользователя.

Для независимой игры потребуется отдельная российская установка v25: серверный Worker-адаптер для Node, локальное SQLite/S3-совместимое хранение, защищённый вход и проверка всей сессии. Можно подготовить **изолированную тестовую базу**, не трогая production D1/R2. Она не будет автоматически содержать старых игроков, настройки или награды. Перенос production требует отдельного согласования, резервов и приёмки; сейчас запрещён.

Нельзя публично размещать QA-сервер, который всем запросам назначает `local-owner`, или выдавать статическую страницу за рабочую игру. Код квеста не помещать в этот открытый репозиторий: для полной установки нужен отдельный закрытый источник и ограниченное право чтения Timeweb.

## Локальные проверки

`npm test` — изолированные проверки транспорта и защиты. `npm run probe` — GET-проверка **с того узла, где выполняется команда**; запуск на ноутбуке не является доказательством российского маршрута. В контейнер не копируются тесты, README, локальные файлы проекта или окружение с секретами.
